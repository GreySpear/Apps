# Kitchen — card layout (backup)

This is a snapshot of the **card-based** Kitchen UI (recipe cards on the home
screen, card-style grocery rows) taken before the switch to the compact-row
design plan from `Kitchen New Design/`.

`index.html` here is a full, standalone copy of the app at that point — open it
directly in a browser to use the old look. It talks to the same Google Sheet
backend (`../backend.gs`) and shares the same local-storage keys as the live
app, so your recipes, groceries, staples, and meal plan are identical either
way.

Kept for reference / rollback only. The live app is `kitchen/index.html`.
