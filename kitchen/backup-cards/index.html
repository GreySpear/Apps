    Sync your recipes and grocery list to one Google Sheet so they're backed up and shared across devices. Everything works offline too — text import always works; URL & photo import need the backend.

    Set-up steps & backend code
    1. Create one Google Sheet, open Extensions → Apps Script.
    2. Paste the backend.gs from the kitchen/ folder, save.
    3. Deploy → New deployment → Web app. Execute as Me, access Anyone.
    4. Copy the Web App URL and paste it above.

    One backend serves everything — recipes, groceries, server-side URL fetch (no CORS), and photo OCR. Three tabs are created automatically: recipes, items, staples. See kitchen/SETUP.md.
